  • Snap: widgets snap to the 12 × 6 grid. The dotted pattern shows the cells. The dashed accent box is where the dragged or resized widget will land.
  • Collisions: widgets in the way move down (vertical compaction). If there is no room, the drop target turns crit and the drop is refused.
  • Handles: top-left drag moves, bottom-right resizes. Minimum 2 × 1. Each widget type has its own minimum (gauge 3 × 3).
  • Tap a widget to open the picker with its current settings. The × removes it (undo is in the toolbar).
  • Layouts are saved as versioned JSON per preset. Presets: Commute, Performance, Minimal, plus the user's own.
